VybeTop traders

Trader leaderboards by mint or wallet

Look up a mint for its top PnL traders, or a wallet for its rank among top traders and its own profit and loss. Realized PnL, volume, and trade count follow the window you pick, on every row in the table.

Windows in the tables are 1d, 7d, and 30d. A mint ranks traders on that token, and a wallet returns its own result for the window you chose. A free API key on Vybe is enough to start. Paid plans raise the rate limit.

Generate a free API key

Endpoints Used:

  • Top Traders API GET /v4/wallets/top-traders
  • Historical Trades API GET /v4/trades
  • Token Details API GET /v4/tokens/{mintAddress}
  • Top Token Holders API GET /v4/tokens/{mintAddress}/top-holders
  • Labeled Programs API GET /v4/programs/labeled-program-accounts

  • Mint leaderboard

    Wallets ranked by realized PnL on the mint you enter.

  • Wallet rank

    Where that wallet sits on the top-trader list for the window.

  • Realized PnL

    Realized and unrealized PnL, volume, and trade count.

  • Wallet detail

    Per-wallet profit and loss when the lookup is a wallet address.

What can I look up?

A mint's top PnL traders, or a wallet's rank and its own profit and loss.

How do I get a Vybe API key?

Generate a free API key on Vybe. A free key starts your first calls. Paid plans raise the rate limit.

Is Top Traders on the free plan?

Yes. The Free plan includes Top Traders, the lowest tier.
